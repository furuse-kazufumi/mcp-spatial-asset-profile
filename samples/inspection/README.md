# Inspection Samples

Point cloud and mesh samples from the Stanford 3D Scanning Repository (Stanford Bunny).

Files from mcp-3d v1 (when available):
- `bunny_full.ply` — Full resolution PLY (35,947 points, ASCII)
- `bunny_binary.ply` — Binary PLY (35,947 points, binary-little-endian)
- `bunny_lod1.npy` — LOD-1 NumPy array (5,000 points)
- `bunny_mesh.npz` — Mesh data (vertices + faces)
- `icosphere.obj` — Wavefront OBJ icosphere mesh

Corresponding v2 asset envelopes: see `spec/examples/`.
